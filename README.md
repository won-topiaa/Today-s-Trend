# 🧭 오늘의 트렌드

**젊은 세대와 가까워지는 첫걸음**

자녀와, 학생과, 젊은 동료와 한마디라도 더 나누고 싶은 40~60대 성인을 위한 트렌드 안내 사이트입니다.
젊은 사람들에게 다가가기 위해 꼭 알아야 할 요즘 트렌드를 쉽고 친절하게 알려 드립니다.

## 주요 기능

| 메뉴 | 설명 |
|------|------|
| 🏠 **홈** | 매일 바뀌는 "오늘의 신조어"와 주요 메뉴 바로가기 |
| 📖 **신조어 사전** | 신조어·줄임말·유행어의 뜻, 예시 대화, 사용 팁. 검색과 난이도·종류 필터 지원 |
| 🔥 **요즘 유행** | 음식·카페, 콘텐츠·밈, 놀이·문화, 앱·쇼핑, 패션·뷰티, 건강·생활 분야의 최신 유행. 대화 시작 멘트 포함 |
| 💬 **대화 팁** | 대화 시작하는 법, 피해야 할 대화 습관, 신조어 사용 요령, 디지털 소통 예절 |
| ✏️ **퀴즈** | 신조어·트렌드 상식 퀴즈로 나의 트렌드 감각 확인 |

## 중장년층을 배려한 설계

- **글자 크기 조절**: 화면 위 "보통 / 크게 / 아주 크게" 버튼으로 언제든 조절 (선택은 자동 저장)
- **큰 글씨와 높은 대비**: 기본 글자 크기 18px 이상, 읽기 편한 색 대비
- **단순한 화면 구성**: 다섯 개의 큰 메뉴, 한 화면에 한 가지 내용
- **키보드·스크린리더 접근성**: 건너뛰기 링크, 명확한 초점 표시, 의미 있는 마크업

## 실행 방법

별도의 설치나 서버 없이 동작하는 정적 웹사이트입니다.

- `index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.
- 또는 간단한 웹 서버로 실행할 수 있습니다:

```bash
# 파이썬이 있는 경우
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### GitHub Pages로 배포하기

1. GitHub 저장소의 **Settings → Pages**로 이동
2. **Source**를 `Deploy from a branch`로 선택
3. 배포할 브랜치와 `/ (root)` 폴더를 선택하고 저장
4. 잠시 후 발급되는 주소로 누구나 접속할 수 있습니다

## 프로젝트 구조

```
├── index.html          # 단일 페이지 (모든 화면 포함)
├── css/
│   └── style.css       # 스타일 (글자 크기 3단계 지원)
├── js/
│   ├── app.js          # 화면 전환·검색·필터·퀴즈 로직 (외부 라이브러리 없음)
│   └── data/
│       ├── meta.js         # 사이트 기준일 등 공통 정보
│       ├── slang-data.js   # 신조어 사전 데이터
│       ├── trends-data.js  # 요즘 유행 데이터
│       ├── guide-data.js   # 대화 팁 데이터
│       └── quiz-data.js    # 퀴즈 데이터
└── README.md
```

## 콘텐츠 업데이트

트렌드는 빠르게 바뀝니다. `js/data/` 폴더의 데이터 파일만 수정하면 화면에 바로 반영됩니다.
새 항목을 추가할 때는 각 파일 안의 기존 항목 형식을 그대로 따라 작성하면 됩니다.
데이터를 갱신한 뒤에는 `js/data/meta.js`의 기준일도 함께 바꿔 주세요.
