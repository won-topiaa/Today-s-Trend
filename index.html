🔥 요즘 유행

요즘 젊은 사람들 사이에서 인기 있는 것들입니다. 카드마다 대화를 시작할 수 있는 한마디도 담았어요.

📋 어떤 기준으로 골랐나요?

여기 실린 유행은 다음 다섯 가지 기준을 모두 충족한 것만 담았습니다.

  1. 확산성 — 한 커뮤니티를 넘어 여러 곳(유튜브·인스타그램·커뮤니티 등)에서 확인될 것
  2. 지속성 — 최소 한 달 이상 유행이 이어질 것 (하루짜리 이슈는 제외)
  3. 세대 대표성 — 10~20대가 주도하는 유행일 것
  4. 대화 활용성 — 어른이 실제 대화 소재로 쓸 수 있을 것
  5. 적절성 — 혐오·차별·정치·사행성 내용은 담지 않을 것

순간순간의 화제는 지금 화제 메뉴에서 실시간 데이터로 따로 보여 드립니다.

📡 지금 화제

사람이 고른 것이 아니라, 공개된 실시간 지표에서 기계가 자동으로 모아 온 목록입니다. "지금 무엇이 화제인지"를 보여 주는 창이니, 모르는 이름이 보이면 젊은 사람에게 물어보는 대화 소재로 써 보세요.

📋 이 목록은 어떻게 만들어지나요?

이 사이트는 트렌드를 두 층으로 나눠 보여 드립니다.

  1. 지금 화제 (이 화면) — 기계가 자동 수집한 정량 지표입니다. 아래 세 곳에서 가져옵니다.
    • 구글 급상승 검색어: 검색량이 갑자기 늘어난 주제 → 화제성
    • 애플뮤직 인기곡 차트: 젊은 층이 실제 많이 듣는 음악 → 문화 소비
    • 위키백과 많이 본 문서: 사람들이 찾아본 인물·작품·사건 → 관심 검증
  2. 요즘 유행·신조어 사전 — 확산성·지속성·세대 대표성·대화 활용성·적절성 다섯 기준으로 사람이 선별하고 설명을 붙인 콘텐츠입니다.

실시간 지표는 "무엇이 화제인가"만 알려 줍니다. 그것이 무엇이고 어떻게 대화에 쓰는지는 요즘 유행과 신조어 사전이 설명해 드립니다.

자동 수집 특성상 사건·사고 등 유행이 아닌 이슈가 섞일 수 있습니다. 데이터는 6시간마다 자동 갱신되며, 접속한 브라우저에서 바로 최신 차트를 불러오기도 합니다.
